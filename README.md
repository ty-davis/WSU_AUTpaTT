# WSU_AUTpaTT

This repository contains all the files necessary to
build and operate the WSU_AUTpaTTv3, a device which
is used to characterize antennas in 3D. Lead by students
at Weber State University, WSU_AUTpaTTv3 is a project
which promotes collaboration and helps students learning
about electromagnetic radiation.

## Usage

The documentation is provided in the `docs/WSU_AUTpaTTv3_docs.pdf`
and outlines the contruction and operation of the device.
