\chapter{Overview}

AUTpaTT v3 (Antenna Under Test Pattern Tracking, Version 3) is a low-cost, open-source 3-axis antenna pattern measurement system designed for education, research, and outreach.

This document is intended for a new user who receives the project files (for example via GitHub), purchases the required hardware, assembles the mechanical and electrical system, loads the firmware, runs the GUI, and successfully performs antenna measurements.

\section{System Goals}

\begin{itemize}
  \item Provide a low-cost, open-source antenna pattern measurement system.
  \item Use commercial off-the-shelf (COTS) and 3D-printed components where possible.
  \item Support three-axis motion (Azimuth, Elevation, Mast/Rotation).
  \item Integrate with software-defined radios (SDRs) for flexible RF measurements.
  \item Offer an easy-to-use GUI for control, data collection, and visualization.
\end{itemize}

\section{Assumed Background}

This guide assumes the user has basic familiarity with:

\begin{itemize}
  \item Microcontrollers and serial communication.
  \item 3D printing and/or mechanical assembly.
  \item Python environments and package installation.
\end{itemize}
