\chapter{Configuration: \texttt{params.json}}

The file \texttt{params.json} contains configuration parameters used by both the firmware and GUI. Typical fields include:

\begin{itemize}
  \item Motor steps per revolution.
  \item Gear ratios for each axis.
  \item Default sweep ranges and step sizes.
  \item SDR sample rates and gains.
  \item Serial port settings (baud rate, timeouts, etc.).
\end{itemize}

\section{Editing Parameters}

Parameters may be edited in several ways:

\begin{itemize}
  \item Directly in a text editor (keeping valid JSON syntax).
  \item Through GUI controls that read and write this file.
\end{itemize}

Document here any parameters that are especially important for calibration and system performance.
