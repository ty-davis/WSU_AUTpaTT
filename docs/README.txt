AUTpaTT v3 LaTeX Documentation
==============================

This folder contains a LaTeX project for the AUTpaTT v3 build and user documentation.

To build:
1. Install a LaTeX distribution (TeX Live, MiKTeX, etc.).
2. In this directory, run:

   pdflatex main.tex
   pdflatex main.tex

The output will be main.pdf containing the compiled documentation.
